# PBL 시작 카드

- 프로젝트 주제:
  사용자가 원하는 주제와 분위기, 상황을 입력하면 가장 잘 어울리는 K-POP 한 곡을 추천하는 검색 서비스

- 사용자는 누구인가:
  특정한 주제나 분위기의 노래를 듣고 싶지만 어떤 곡을 선택해야 할지 바로 떠오르지 않아, 원하는 느낌을 입력하여 새로운 곡을 추천받고 싶은 음악 청취자

- ES로 찾게 할 문서 1건은 무엇인가:
  사용자가 입력한 주제·분위기·조건과 가장 관련성이 높은 K-POP 노래 1곡

- 사용자가 입력할 검색 질문 1:
  "2020년 이후 발매된 우주 느낌의 몽환적인 노래"
  → 우주뿐만 아니라 별, 은하, 행성, 궤도, Universe, Galaxy 등의 연관 키워드까지 고려

- 사용자가 입력할 검색 질문 2:
  "여름 바다를 떠올리게 하는 청량하고 신나는 노래"
  → 여름, 바다뿐만 아니라 파도, 햇살, 해변, 여행 등의 관련 키워드까지 고려

- 사용자가 입력할 검색 질문 3:
  "새벽에 혼자 들을 잔잔하고 몽환적인 노래"
  → 새벽, 밤, 달, 별빛 등의 주제와 잔잔함·몽환적인 분위기를 함께 고려

- 필터에 사용할 분류 필드 후보:
  genre: Dance / Ballad / R&B / Hip-hop / Rock / Electronic
  mood: 청량 / 몽환 / 신남 / 잔잔 / 벅참 / 감성 / 신비 / 강렬
  lyrics_theme: 사랑 / 이별 / 청춘 / 우주 / 여행 / 위로 / 꿈 / 추억
  artist_type: 솔로 / 그룹
  gender_type: 남성 / 여성 / 혼성
  situation: 드라이브 / 새벽 / 여행 / 운동 / 산책 / 공부 / 파티

- 정렬에 사용할 숫자·날짜 필드 후보:
  release_date: 최신 발매순
  bpm: 빠르거나 느린 곡 순
  popularity_score: 인기도 순
  energy_score: 에너지 정도 순
  _score: 검색어와의 관련성이 높은 순

- Dashboard에서 답할 질문 1:
  "현재 음악 데이터에서 주제별로 어떤 분위기와 장르의 곡이 구성되어 있으며, 특정 주제나 분위기의 데이터가 부족하거나 편중되어 있지는 않은가?"

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.
- 실제 개인정보·고객 데이터는 사용하지 않습니다.
- 약 5,000건의 합성 K-POP 곡 데이터를 사용합니다.
- 실제 가사 전문은 저장하지 않고 가사 키워드, 가사 주제, 콘셉트 등의 합성 메타데이터를 검색에 활용합니다.
