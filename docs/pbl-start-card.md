# PBL 시작 카드

- 프로젝트 주제:
  기억나는 키워드와 연관 의미로 원하는 K-POP 한 곡 찾기

- 사용자는 누구인가:
  정확한 노래 제목이나 가수는 기억나지 않지만,
  가사에서 기억나는 단어, 노래의 주제, 분위기 등을 이용해 원하는 곡을 찾고 싶은 음악 청취자

- ES로 찾게 할 문서 1건은 무엇인가:
  사용자의 검색어와 의미적으로 가장 관련성이 높은 K-POP 노래 1곡

- 사용자가 입력할 검색 질문 1:
  `우주`
  → 우주라는 단어뿐 아니라 별, 별빛, 행성, 은하, 달, 궤도, Universe, Galaxy 등
  우주와 관련된 키워드를 가진 노래가 함께 검색되도록 함.

- 사용자가 입력할 검색 질문 2:
  `여름 바다`
  → 바다, 파도, 햇살, 해변, 여행, 여름밤 등의 연관 키워드를 가진 노래 중
  청량하거나 신나는 분위기의 곡을 검색함.

- 사용자가 입력할 검색 질문 3:
  `새벽에 우주를 떠다니는 것 같은 몽환적인 노래`
  → 새벽, 밤, 별, 무중력, 궤도, 우주 등의 키워드와
  몽환적·신비로운 분위기를 함께 고려하여 가장 관련성이 높은 곡을 검색함.

- 필터에 사용할 분류 필드 후보:
    - genre: Dance / Ballad / R&B / Hip-hop / Rock / Electronic 등
    - mood: 청량 / 몽환 / 신남 / 잔잔 / 벅참 / 감성 / 신비 / 강렬 등
    - lyrics_theme: 사랑 / 이별 / 청춘 / 우주 / 여행 / 위로 / 꿈 / 추억 등
    - artist_type: 솔로 / 그룹
    - gender_type: 남성 / 여성 / 혼성
    - situation: 드라이브 / 새벽 / 여행 / 운동 / 산책 / 공부 / 파티 등

- 정렬에 사용할 숫자·날짜 필드 후보:
    - release_date: 최신 발매순
    - bpm: 빠른 곡 / 느린 곡 순
    - popularity_score: 인기도가 높은 곡 순
    - energy_score: 에너지가 높은 곡 순
    - _score: 사용자의 검색어와 관련성이 높은 곡 순

- Dashboard에서 답할 질문 1:
  노래의 가사 주제(lyrics_theme)에 따라 어떤 분위기(mood)와 장르가 주로 나타나는가?
  예: '우주' 주제의 곡은 몽환·신비 분위기와 Electronic 장르의 비율이 높은가?

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.

- 실제 개인정보·고객 데이터는 사용하지 않습니다.

- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용합니다.

- 실제 K-POP 가사 전문을 수집하지 않고,
  검색 실습을 위해 생성한 가상의 곡 데이터와
  `lyrics_keywords`, `lyrics_theme`, `concept_keywords` 등의 메타데이터를 사용합니다.

- 약 5,000건의 합성 곡 데이터를 생성하며,
  동일한 결과를 재현할 수 있도록 고정 seed를 사용합니다.

- 단순 랜덤 조합이 아닌 생성 규칙을 적용합니다.
  예를 들어 `lyrics_theme = 우주`인 경우
  별, 은하, 행성, 달, 궤도, 무중력, 별빛 등의 키워드가
  높은 확률로 포함되도록 데이터를 생성합니다.

- Elasticsearch에서는 제목, 가사 키워드, 주제, 콘셉트 등의 필드를 함께 검색하고,
  필드별 boost를 적용하여 검색 결과의 관련성을 조정합니다.

- `우주 → 별, 행성, 은하, Universe, Galaxy`와 같은 검색은
  synonym/연관어 처리를 이용해 확장하고,
  이후 AI Search 단계에서는 자연어의 의미까지 고려하는 검색으로 확장합니다.
